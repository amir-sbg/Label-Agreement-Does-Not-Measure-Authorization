# Data

`synthetic_panel/` is fully synthetic, regenerated by `scripts/generate_synthetic.py`, and safe to share.

COBRE and FBIRN are access-restricted under their data use agreements, so nothing derived from them is committed here. With authorized access, point `NEUROMARK_ROOT` at the directory that holds the NeuroMark `Data/` and `Results/` trees listed in `configs/sources.yaml`, then run:

```bash
python scripts/build_cards.py        # -> data/cards/        (Evidence Cards)
python scripts/build_benchmark.py    # -> data/real_panel/   (230 cases + oracle)
```

`scripts/verify_sources.py` checks every source artifact against the SHA-256 recorded in its Evidence Card. Source files are opened read-only.
